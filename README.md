# 🍫 Chocolate Sales Analysis – EDA & ML Pipeline

A complete Chocolate Sales Data Analysis project using Python.

## 📌 Objective
Analyze chocolate sales data to identify:
- Sales trends
- Seasonal effects
- Product and brand performance
- Geographic and store performance
- Customer behaviour
- Profit patterns

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Project Features
- Data loading and dataset overview
- Missing-value analysis
- Data cleaning and feature engineering
- Revenue and profit KPIs
- Product and brand analysis
- Country and store analysis
- Customer analysis
- Monthly and seasonal sales trends
- Correlation analysis
- Profit prediction using machine learning

## 📁 Dataset Files Required
Place these files in a `data/` folder before running locally:
- `calendar.csv`
- `customers.csv`
- `products.csv`
- `sales.csv`
- `stores.csv`

> The uploaded notebook was originally configured for Kaggle paths. Update the file paths in the data-loading cell when running locally.

## 🚀 How to Run
```bash
pip install -r requirements.txt
jupyter notebook Chocolate_Sales_Analysis.ipynb
```
